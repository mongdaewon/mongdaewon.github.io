**LazyWindow - 키보드 창 배치**

**⌃⌥ (Control + Option)** 를 누른 채 방향키를 누릅니다. 이게 전부입니다.

## 시작하기 전에

다른 앱의 창을 옮기려면 손쉬운 사용(접근성) 권한이 필요합니다. 메뉴 막대 아이콘을 눌러 **Grant accessibility permission…** 을 선택한 뒤, 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 LazyWindow를 켜세요. 권한을 주면 이 메뉴는 사라집니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| ⌃⌥ ← / → | 왼쪽·오른쪽 1/2. 다시 누르면 2/3, 또 누르면 1/3. |
| ⌃⌥ ↑ / ↓ | 위·아래 1/2. 다시 누르면 왼쪽 모서리, 또 누르면 오른쪽 모서리. |
| ⌃⌥ ← ↑ | ⌃⌥를 누른 채 방향키 두 개를 누르면 모서리. 순서는 상관없습니다. |
| ⌃⌥ ↩ | 화면 가득 채우기. |
| ⌃⌥ C | 가운데 정렬. 최대화 상태면 2/3로 줄인 뒤 가운데로. |
| ⌃⌥⌘ ← / → | 왼쪽 모니터, 오른쪽 모니터로 이동. |
| ⌃⌥⇧ ← / → | 배치하기 전 크기와 자리로 되돌리기. |

## 같은 키를 반복하면

같은 방향을 다시 누르면 같은 동작을 반복하는 대신 크기가 순환합니다.

- **⌃⌥→** 반복: 오른쪽 1/2 → 오른쪽 2/3 → 오른쪽 1/3 → 오른쪽 모니터에서 다시 1/2.
- **⌃⌥↑** 반복: 상단 1/2 → 좌측 상단 → 우측 상단 → 다시 상단 1/2.

반대쪽 화살표를 누르면 현재 비율을 유지한 채 반대편으로 갑니다. 창을 직접 옮기거나 크기를 바꾸면 다음 입력은 1/2부터 시작합니다.

## 설정

메뉴 막대 아이콘 → **Settings…**

- **Launch at login** — 로그인할 때 LazyWindow를 실행합니다.
- **Hide the menu bar icon** — 아이콘을 숨겨도 단축키는 그대로 동작합니다. 설정 창을 다시 열려면 LazyWindow를 한 번 더 실행하세요.
- **Continue onto the next display** — 끄면 옆 모니터로 넘어가지 않고 현재 모니터에서만 크기를 순환합니다.

## 특정 앱 제외하기

배치하면 안 되는 앱이 있다면, 그 앱을 앞에 둔 상태에서 LazyWindow 메뉴를 열고 **Ignore "앱 이름"** 을 선택하세요. 다시 선택하면 해제됩니다.

## 알아두면 좋은 것

- 단축키는 글자가 아니라 자판 위치를 따르므로 한글 입력 중에도 그대로 동작합니다.
- 되돌리기는 LazyWindow가 한 번이라도 배치한 창에만 동작합니다.
- 전체 화면 창이나 크기 변경을 거부하는 창은 건드리지 않습니다.
